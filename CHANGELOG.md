# Changelog

All notable changes to `phil/typography` will be documented in this file.

Updates should follow the [Keep a CHANGELOG](https://keepachangelog.com/) principles.

## NEXT - YYYY-MM-DD

### Added

- `Locale`, a language with an optional script and region, and its candidates from the most precise.
- `Run`, the text nodes of one block in parts, with locked parts for protected elements, and `Fixer`, the interface
  of one rule.
- The fixers `UnicodeNormalization`, `Ellipsis`, `Dimension`, `Dash` with `DashStyle`, `SmartQuotes`, `CurlyQuote`,
  `NoSpaceBeforeComma`, `SpaceBeforePunctuation` with `FrenchSpacing` for France and Canada, `Trademark`, `Unit`,
  `Hyphen` and `WordBreak`, the zero-width spaces between Thai words from the ICU dictionary; emoji sequences left byte
  for byte by every one. `SmartQuotes` opens a quote after `>`, the end of a tag escaped as text, and closes an inner
  one before `<`.
- `QuoteStyle` and `QuoteStyles`: the quotation marks of 66 languages and regions, after the Unicode CLDR.
- `Patterns`, `Hyphenator` and `Dictionary`: Liang's hyphenation algorithm written from scratch, never before a
  combining mark, with the hyph-utf8 patterns of 69 languages whose licence permits them, their exceptions and
  minimum lengths, recorded in `data/LICENSES`, and patterns written from scratch under MIT for Czech, Hungarian,
  Armenian, Indonesian, Latvian, Macedonian and Romanian, generated by `bin/generate-patterns.php` from the
  orthographic rules of each language and tested on lists of common words; Armenian and Macedonian are experimental,
  served only by a `Dictionary` built with them (`Dictionary::EXPERIMENTAL`).
- `Typographer`: HTML fragments, whole documents and plain text fixed through `Dom\HTMLDocument`, text only, block by
  block; `pre`, `code`, `kbd`, `script`, `style` and `textarea` protected by default, the list configurable; `<` and
  `>` escaped in attribute values, as the current HTML standard serializes them.
- `Preset`, the fixers of each locale by name and in order, and `Typographers`, one typographer per locale, configured
  by fixer names, those of 64 locales kept at most; `Typographers::fixHtml()`, each passage whose `lang` names another
  language fixed by the typographer of that language.
- `TypographyException`, implemented by `InvalidLocale`, `UnsupportedLanguage` and `UnknownFixer`.
- The documentation in `doc/`, one file per topic, indexed by the README.
- `CONTRIBUTING.md`, `SECURITY.md` and `CODE_OF_CONDUCT.md`.
